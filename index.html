Distributed Edge Persistence via Turso libSQL

Instead of centralizing the database in a traditional monolithic region, the system deploys Turso (libSQL). Database queries execute in sub-millisecond edge replicas with automatic synchronization, maintaining full SQLite ACID transactional integrity while minimizing client response latency worldwide.

Secure S3/R2 Document & Asset Vault

Equipment datasheets, field commissioning photos, and PDF sign-offs are securely routed to Cloudflare R2 via S3-compatible endpoints. The app leverages cryptographic presigned upload tokens, eliminating server upload bottlenecks and avoiding costly cloud egress fees.

Centralized SecretOps via Doppler

All credentials, API tokens, and database connection strings are unified under Doppler SecretOps. Environment variables are injected dynamically during build and runtime on Render and GitHub Actions, eliminating local .env file drift and credential leakage.

Zero-Cost Automated Disaster Recovery Pipeline

A daily scheduled GitHub Actions workflow performs a automated backup cycle: extracting an atomic snapshot from Turso, validating relational checksums, storing encrypted archives, and executing dry-run tests via the custom restore-db.js recovery engine. In a catastrophic outage, full restoration completes in under 60 seconds at zero recurring infrastructure cost.
